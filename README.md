# Blind AI Assistnat
This is the app for the people who cant see this beautiful world from their own eyes But Why we cant help them to felt the world from our Technology.The Application uses Gemini to communicate with the user and provided them regarding the answer regarding the questions. But I didnt stop their as we added feaures and feature to facilitate the specials people to do daily task works without see the interface or clicking the button randomly.
## Features

*Device Assistance:** Control Wi-Fi, flashlight, volume, battery status, alarms, and timers entirely by voice.
* **Camera Vision:** Scene description, text/OCR reading, currency recognition, and object identification using Android Camera2 and Gemini multimodal analysis.
* **Communication & Automation:** Voice-based calling, contact lookup, and WhatsApp messaging/notification reading via Android AccessibilityService.
* **YouTube Navigation:** Voice-driven search, result filtering (e.g., stripping out Shorts and irrelevant UI), and playback control.
* **Bilingual Support:** Native handling for both English and Roman Urdu voice commands.
